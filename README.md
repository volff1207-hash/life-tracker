# Life Tracker

Персональный трекер жизни с привычками, тренировками, режимом сна, курением и push-уведомлениями.

## Установка

### 1. Установи Node.js

Скачай с [nodejs.org](https://nodejs.org) (версия 18+). Проверь после установки:
```
node --version
```

### 2. Установи зависимости

Открой папку с проектом в терминале и запусти:
```
npm install
```

### 3. Запусти

```
npm start
```

Откроет сервер на `http://localhost:3000`. В терминале также покажет IP для доступа с телефона.

### 4. Открой на телефоне

Телефон и компьютер должны быть в **одной Wi-Fi сети**.

Открой браузер на телефоне и введи адрес вида:
```
http://192.168.1.X:3000
```
(точный IP покажется в терминале после `npm start`)

### 5. Добавь на экран домой

**iPhone (Safari):**
Открой сайт → нажми кнопку "Поделиться" (квадрат со стрелкой) → "На экран домой"

**Android (Chrome):**
Открой сайт → меню (три точки) → "Добавить на главный экран"

### 6. Push-уведомления

VAPID ключи для push-уведомлений генерируются автоматически при первом запуске и сохраняются в базе данных (`db.sqlite`).

При открытии приложения появится баннер с запросом разрешения на уведомления — нажми "Включить".

Управление уведомлениями — кнопка шестерёнки в правом верхнем углу.

> **Важно:** Push-уведомления работают только при открытом соединении с сервером.
> Для работы с телефона по локальной сети — сервер должен быть запущен на компьютере.
